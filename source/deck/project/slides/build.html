Abu Dhabi 2021 · race replay · unofficial fan project

Read it left to right. Three open sources go in. The kernel turns them into one function: give it a race time, it returns where every car is. Because nothing is simulated step by step, jumping to any moment is instant. Four parts draw from that function, and everything ships as a single HTML file of 739 kilobytes; all geometry is generated in code, so there are no model or image files. The 3D library is the one thing loaded from the network.
