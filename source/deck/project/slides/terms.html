Sharing it

A fan project, shared for free

Unofficial

We made this as fans. It has no link to the sport’s organisers, the teams or the drivers, and it uses no logos or sponsor artwork. Names appear as plain text.

Not for sale

The lap times we use are shared for non-commercial projects only. So the replay stays free: no ads, no paid version.

Thanks to

The Jolpica F1 API for the timing data, OpenStreetMap contributors for the map, RaceFans for the tyre stints, and Three.js for the 3D.

The credits and the licences are in the project’s readme.
